# 参考站 UI 调研（game.hullqin.cn）

> 截图见 `screenshots/`。调研时间：2026-08-13。

## 整体风格

- 浅色极简风：浅灰底（#eee）、居中窄栏、胶囊按钮列表。
- 首页：标题「桌游合集」+ 每款游戏一个胶囊按钮（彩色六边形图标 + 名称），底部按人数筛选（全部/2人/3人/…/更多人）。
- 每款游戏一个主题色：五子棋=橙、斗地主=蓝、一夜狼=红、阿瓦隆=紫。
- 登录用微信/QQ（我们不做登录，用昵称即可）。

## 游戏落地页（四款一致）

- 左上「桌游列表」返回；居中游戏图标 + 名称；公告条；按钮：功能介绍/查看规则、本地对战（仅五子棋）、创建房间、输入房间号 + 进入房间。
- 见 `screenshots/wuziqi_room.png`、`ddz_landing.png`、`yyl_landing.png`、`awl_landing.png`。

## 五子棋对局页（本地对战）

- 顶部：返回主页、标题、模式（本地对战）、规则变体（无禁手/一手交换/Swap2/有禁手/RIF/山口/索索夫8/塔拉山口10）。
- 先手/后手选择（黑白棋子图标），落子前可切换。
- 轮次提示「请黑方下棋」。
- 棋盘：15×15，橙色底 + 红色网格线，简洁。

## 对我们的启发

- 保留：每游戏主题色、人数筛选、房间号加入、规则说明入口、五子棋本地对战。
- 升级：深色「桌游夜」质感、毛玻璃卡片、座位围坐布局、聊天侧栏、动效与音效占位。
- 交互：房间内点击座位入座、准备/开始、房主设置；对局中按玩家视角下发状态（隐藏信息只在服务端）。
